# Changelog

## v3.0.0 — 2026-11-09

- **10,598 skills**: +5,430 new profession skills across 181 new categories (healthcare specialties, legal practice areas, engineering disciplines, trades, hospitality, logistics, aviation, maritime, agriculture, energy, finance, real estate, care work, media, science and more), taking the collection past 10,000 skills.
- Every new skill deduped against all existing slugs (0 collisions) and validated for frontmatter compliance (100%).
- 122 plugins unchanged (120-plugin GTM + Community suite, Auto-GTM Agent, Resume Optimizer v2).

## 2.0.0 — 2026-11-09

The collection grows from a skill library into a validated skill +
plugin platform.

### Added

- **20 new skills** under `skills/` (flat layout), covering a full GTM
  loop (ICP and offer research, lead list building, personalised cold
  email, sponsor and partner outreach, reply triage and booking,
  follow-up and learning loop), agent services (agent findability audit,
  automation agency, WhatsApp AI agent, voice AI receptionist, agent
  plugin builder, agent setup service, sponsor audience claims,
  invoice and reconciliation integrity), content (AI avatar critique,
  video replica, objection to content, DESIGN.md), productivity
  (project manager, with its stdlib CLI) and career (career
  opportunities tracker). Every new skill meets the bar in QUALITY.md.
- **Resume Optimizer v2.0.0 plugin**: `resume-optimizer/plugin/` ships an
  MCP server and a REST API (`score_resume`, `extract_keywords`,
  `gap_analysis`, `check_format`), an OpenAI-style `ai-plugin.json` +
  `openapi.json`, and a Claude Code manifest under
  `resume-optimizer/.claude-plugin/`.
- **Auto-GTM Agent plugin docs**: a truthful metadata-only Claude Code
  manifest plus `auto-gtm-agent/PLUGIN.md` documenting its CLI actions
  contract (it provides no MCP server, and now says so).
- **Root Claude Code marketplace** (`.claude-plugin/marketplace.json`)
  listing resume-optimizer, auto-gtm-agent and gtm-community-plugins.
- **`catalog.json`** — a machine-readable registry of every skill and
  plugin, generated by `tools/build_catalog.py`, plus a generated
  A–Z `skills/INDEX.md`.
- **Validation tooling**: `tools/validate.py` (frontmatter compliance,
  JSON manifests, marketplace paths, catalog counts, README links) and
  `tests/test_collection.py` (stdlib unittest, no pytest needed).
- **`plugins/README.md`** — the plugin index explaining the three plugin
  routes (Claude Code marketplace, MCP servers, REST / ai-plugin.json).
- **`QUALITY.md`** — the quality contract for future contributions.
- **`SECURITY.md`** and **`docs/continuous-integration.md`** (a ready-to
  paste GitHub Actions workflow; see that file for why it is not
  committed under `.github/workflows/`).

### Changed

- README rewritten with verified counts (5,168 skills under `skills/`,
  107 categories, 122 plugins), install paths for Claude Code,
  Claude.ai and MCP clients, full catalog tables for the new skills and
  all plugins, and a collection-health note.
- CONTRIBUTING rewritten around the quality bar and the validation
  requirement.
- `.gitignore` extended with Python caches.

### Prior state (1.x)

Before 2.0.0 the repository held 5,148 skills under `skills/`, the
Auto-GTM Agent v0.1, the Resume Optimizer skill (v1.3.1 files, without
the v2 plugin), the 120-plugin GTM Community Plugins suite, and the
skill template, with a short README and no registry, validator or root
marketplace.
