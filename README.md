# Claude Skills Collection

The largest open-source collection of Claude AI skills — **5,153 skills across 106 categories**.

## What Are Claude Skills?

Skills are structured SKILL.md files that give Claude specific frameworks, workflows, and quality standards for any task. Drop them into Claude Projects or reference them in prompts to get consistently high-quality, professional outputs.

## Quick Start

1. Browse the `skills/` directory for what you need
2. Copy the SKILL.md file into your Claude Project
3. Ask Claude to use the skill — it follows the workflow automatically

## Skill Template

Every skill follows a standardized format:

```yaml
---
name: skill-name
description: What the skill does
category: Category Name
version: 1.0
---
# Skill Name
## Workflow (step-by-step process)
## Output Format (structured deliverable)
## Quality Checklist (validation criteria)
```
