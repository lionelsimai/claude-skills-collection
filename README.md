## What Are Claude Skills?

Claude Skills are structured instruction sets that give Claude specialized abilities. Instead of prompting from scratch, skills provide pre-built workflows for complex tasks.

**Without skills:** Claude is a smart generalist.  
**With skills:** Claude is a specialist who knows exactly how to execute.

Each skill includes:
- **Triggers** — When Claude should use the skill
- **Workflow** — Step-by-step process to follow
- **Output format** — Exactly how results are structured
- **Quality checklist** — Standards for the output

## ⚡ Setup (Under 15 Minutes)

### Option 1: Claude Projects (Easiest)
1. Go to [claude.ai](https://claude.ai) → Create a **new Project**
2. Upload skills as **Project Knowledge** files
3. Start chatting — Claude automatically activates the right skill

**Pro tip:** Group related skills in themed projects (e.g., "Content Machine" with all content skills).

### Option 2: Claude API / System Prompts
1. Include skill content in your system prompt
2. Reference specific skills in your instructions
3. Claude follows the skill workflows automatically

### Option 3: Claude Desktop + MCP
1. Clone this repo
2. Configure MCP to point to the skills directory
3. Claude accesses skills on demand

### Option 4: Copy & Paste
1. Open any skill's `SKILL.md`
2. Copy the content
3. Paste into Claude as your first message
4. Follow up with your request

## 🛠 Creating Custom Skills

Use the [skill-template](skill-template/) to create your own:

```
your-skill/
├── SKILL.md          # Main skill file (required)
├── references/       # Supporting docs, examples (optional)
└── scripts/          # Helper scripts (optional)
```

Every skill needs:
1. **Frontmatter** — Name, description, and trigger conditions
2. **Workflow** — Step-by-step process
3. **Output format** — How results should look
4. **Quality checklist** — Standards to meet

See [CONTRIBUTING.md](CONTRIBUTING.md) for full guidelines.

## 💡 Power User Tips

### Stack Skills
Use multiple skills together for complex workflows:
```

```

### Chain Outputs
Feed one skill's output into another:
```

discovery-call-prep → proposal-generator → contract-drafter
```
