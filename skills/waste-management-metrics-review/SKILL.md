# Metrics & Outcomes Review — Waste Management

Track, interpret and act on the outcome metrics that matter for a waste operations manager. The deliverable is a metrics dashboard definition and an interpretation/action review.
This skill is written for a waste operations manager working with households, businesses and councils in waste facilities and collection rounds.

## When to use
- You are a waste operations manager preparing, delivering or reviewing this part of your work in waste facilities and collection rounds.
- You need a defensible, repeatable approach that produces a metrics dashboard definition and an interpretation/action review.
- A colleague, auditor or client asks how this was done and what evidence supports it.

## Key Concepts
| Term | Meaning |

## Workflow
1. **Step 1** - Define each metric precisely — start with collection completion — including source data in waste transfer notes and collection method
2. **Step 2** - Set review cadence and comparison baselines so trends, not single data points, drive decisions
3. **Step 3** - Investigate movements before celebrating or panicking: check data quality, case mix and one-off causes
4. **Step 4** - Link metric movements to practice changes and to risks such as hazardous waste mishandling; test one change at a time where possible
5. **Step 5** - Report results honestly to stakeholders in waste facilities and collection rounds, including where outcomes fell short and what changes

## Output Format
**Context:** [Situation in waste facilities and collection rounds] | **Objective:** [What this must achieve] | **Audience:** [households, businesses and councils and other stakeholders]

The finished output is a metrics dashboard definition and an interpretation/action review, structured as:
1. Summary of position and evidence
2. Detail, following the workflow above
3. Decisions, actions, owners and dates
4. Review point and escalation route

### Action Plan
1. **Immediate:** Confirm scope, consent and the evidence available in waste transfer notes.
2. **Short-term:** Complete the workflow steps and record outcomes against collection completion.
3. **Medium-term:** Review results, close actions, and update local procedures in waste facilities and collection rounds.

## Guardrails & Quality Checks
- Never let this happen: hazardous waste mishandling.
- Never let this happen: vehicle accidents.
- Never let this happen: site fires.
- Work only within the competence and authority of a waste operations manager; escalate or refer anything beyond it.
- Record facts and observations, not speculation, and keep records confidential to waste facilities and collection rounds's rules.
- Verify names, dates, figures and measurements twice before anything is issued or signed off.
- Use only real, verified information from the case in hand — never invent results, credentials or evidence.
