# Assessment & Findings Report — Valuation & Appraisal

Assess lenders, buyers, sellers and investors and write a defensible findings report as a chartered valuation surveyor. The deliverable is a structured assessment report with findings, evidence and recommendations.
This skill is written for a chartered valuation surveyor working with lenders, buyers, sellers and investors in properties and surveying offices.

## When to use
- You are a chartered valuation surveyor preparing, delivering or reviewing this part of your work in properties and surveying offices.
- You need a defensible, repeatable approach that produces a structured assessment report with findings, evidence and recommendations.
- A colleague, auditor or client asks how this was done and what evidence supports it.

## Workflow
1. **Step 1** - Review the intake record and valuation reports so the assessment builds on verified information, not assumptions
2. **Step 2** - Carry out the assessment using valuation software, following the recognised method for properties and surveying offices
3. **Step 3** - Compare findings against the benchmarks behind report turnaround and note where evidence is strong, weak or missing
4. **Step 4** - Draft the report: findings first, then interpretation, then recommendations in priority order
5. **Step 5** - Check the draft for accuracy and for overvaluation losses; have it reviewed where the profession's standards require a second sign-off

## Guardrails & Quality Checks
- Never let this happen: overvaluation losses.
- Never let this happen: missed defects affecting value.
- Never let this happen: conflicts undeclared.
- Work only within the competence and authority of a chartered valuation surveyor; escalate or refer anything beyond it.
- Record facts and observations, not speculation, and keep records confidential to properties and surveying offices's rules.
- Verify names, dates, figures and measurements twice before anything is issued or signed off.
- Use only real, verified information from the case in hand — never invent results, credentials or evidence.
