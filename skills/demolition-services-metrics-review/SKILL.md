# Metrics & Outcomes Review — Demolition Services

Track, interpret and act on the outcome metrics that matter for a demolition contractor. The deliverable is a metrics dashboard definition and an interpretation/action review.
This skill is written for a demolition contractor working with developers, councils and property owners in demolition sites.

## When to use
- You are a demolition contractor preparing, delivering or reviewing this part of your work in demolition sites.
- You need a defensible, repeatable approach that produces a metrics dashboard definition and an interpretation/action review.
- A colleague, auditor or client asks how this was done and what evidence supports it.

## Key Concepts
| Term | Meaning |
|------|---------|
| Soft strip | removing non-structural elements before demolition |
| Asbestos survey | inspection identifying asbestos before work starts |
| Arisings | materials produced by demolition for reuse or disposal |

## Workflow
1. **Step 1** - Define each metric precisely — start with project completion times — including source data in demolition plans and collection method
2. **Step 2** - Set review cadence and comparison baselines so trends, not single data points, drive decisions
3. **Step 3** - Investigate movements before celebrating or panicking: check data quality, case mix and one-off causes
4. **Step 4** - Link metric movements to practice changes and to risks such as asbestos exposure; test one change at a time where possible
5. **Step 5** - Report results honestly to stakeholders in demolition sites, including where outcomes fell short and what changes

## Guardrails & Quality Checks
- Never let this happen: asbestos exposure.
- Never let this happen: uncontrolled collapse.
- Never let this happen: dust and noise breaches.
- Work only within the competence and authority of a demolition contractor; escalate or refer anything beyond it.
- Record facts and observations, not speculation, and keep records confidential to demolition sites's rules.
- Verify names, dates, figures and measurements twice before anything is issued or signed off.
- Use only real, verified information from the case in hand — never invent results, credentials or evidence.
