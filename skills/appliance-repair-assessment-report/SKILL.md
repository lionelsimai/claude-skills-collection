# Assessment & Findings Report — Appliance Repair

Assess homeowners, landlords and retailers and write a defensible findings report as a appliance repair technician. The deliverable is a structured assessment report with findings, evidence and recommendations.
This skill is written for a appliance repair technician working with homeowners, landlords and retailers in customers' homes and workshops.

## When to use
- You are a appliance repair technician preparing, delivering or reviewing this part of your work in customers' homes and workshops.
- You need a defensible, repeatable approach that produces a structured assessment report with findings, evidence and recommendations.
- A colleague, auditor or client asks how this was done and what evidence supports it.

## Workflow
1. **Step 1** - Review the intake record and job cards so the assessment builds on verified information, not assumptions
2. **Step 2** - Carry out the assessment using multimeters, following the recognised method for customers' homes and workshops
3. **Step 3** - Compare findings against the benchmarks behind first-time fix rate and note where evidence is strong, weak or missing
4. **Step 4** - Draft the report: findings first, then interpretation, then recommendations in priority order
5. **Step 5** - Check the draft for accuracy and for electric shock; have it reviewed where the profession's standards require a second sign-off

- Never let this happen: electric shock.
- Never let this happen: gas appliance risks.
- Never let this happen: repeat faults.
- Work only within the competence and authority of a appliance repair technician; escalate or refer anything beyond it.
