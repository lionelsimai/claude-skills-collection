# Metrics & Outcomes Review — Mine Operations

Track, interpret and act on the outcome metrics that matter for a mine operations manager. The deliverable is a metrics dashboard definition and an interpretation/action review.
This skill is written for a mine operations manager working with mining companies and mineral buyers in mines and processing plants.

## When to use
- You are a mine operations manager preparing, delivering or reviewing this part of your work in mines and processing plants.
- You need a defensible, repeatable approach that produces a metrics dashboard definition and an interpretation/action review.
- A colleague, auditor or client asks how this was done and what evidence supports it.

## Key Concepts
| Term | Meaning |
|------|---------|
| Grade | the concentration of valuable mineral in ore |
| Ventilation | supplying fresh air and removing gases underground |
| Stope | an excavated area from which ore is extracted |

## Workflow
1. **Step 1** - Define each metric precisely — start with production tonnage — including source data in production reports and collection method
2. **Step 2** - Set review cadence and comparison baselines so trends, not single data points, drive decisions
3. **Step 3** - Investigate movements before celebrating or panicking: check data quality, case mix and one-off causes
4. **Step 4** - Link metric movements to practice changes and to risks such as underground incidents; test one change at a time where possible
5. **Step 5** - Report results honestly to stakeholders in mines and processing plants, including where outcomes fell short and what changes

## Guardrails & Quality Checks
- Never let this happen: underground incidents.
- Never let this happen: ventilation failures.
- Never let this happen: equipment breakdowns.
- Work only within the competence and authority of a mine operations manager; escalate or refer anything beyond it.
- Record facts and observations, not speculation, and keep records confidential to mines and processing plants's rules.
- Verify names, dates, figures and measurements twice before anything is issued or signed off.
- Use only real, verified information from the case in hand — never invent results, credentials or evidence.
