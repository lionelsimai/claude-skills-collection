# Metrics & Outcomes Review — Maritime Law

Track, interpret and act on the outcome metrics that matter for a maritime solicitor. The deliverable is a metrics dashboard definition and an interpretation/action review.
This skill is written for a maritime solicitor working with ship owners, insurers and cargo interests in a shipping law firm and admiralty courts.

## When to use
- You are a maritime solicitor preparing, delivering or reviewing this part of your work in a shipping law firm and admiralty courts.
- You need a defensible, repeatable approach that produces a metrics dashboard definition and an interpretation/action review.
- A colleague, auditor or client asks how this was done and what evidence supports it.

## Workflow
1. **Step 1** - Define each metric precisely — start with case resolution times — including source data in charterparties and collection method
2. **Step 2** - Set review cadence and comparison baselines so trends, not single data points, drive decisions
3. **Step 3** - Investigate movements before celebrating or panicking: check data quality, case mix and one-off causes
4. **Step 4** - Link metric movements to practice changes and to risks such as cargo deadlines missed; test one change at a time where possible
5. **Step 5** - Report results honestly to stakeholders in a shipping law firm and admiralty courts, including where outcomes fell short and what changes
