# Assessment & Findings Report — Forestry Management

Assess timber buyers, landowners and conservation bodies and write a defensible findings report as a forest manager. The deliverable is a structured assessment report with findings, evidence and recommendations.
This skill is written for a forest manager working with timber buyers, landowners and conservation bodies in forests and woodland estates.

## When to use
- You are a forest manager preparing, delivering or reviewing this part of your work in forests and woodland estates.
- You need a defensible, repeatable approach that produces a structured assessment report with findings, evidence and recommendations.
- A colleague, auditor or client asks how this was done and what evidence supports it.

## Workflow
1. **Step 1** - Review the intake record and management plans so the assessment builds on verified information, not assumptions
2. **Step 2** - Carry out the assessment using harvesters, following the recognised method for forests and woodland estates
3. **Step 3** - Compare findings against the benchmarks behind timber yield and note where evidence is strong, weak or missing
4. **Step 4** - Draft the report: findings first, then interpretation, then recommendations in priority order
5. **Step 5** - Check the draft for accuracy and for illegal felling; have it reviewed where the profession's standards require a second sign-off
