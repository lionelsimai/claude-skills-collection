# Webinar Planner

## Output Format

```markdown
# Webinar Plan: [Title]

## Webinar Details
- **Topic**: [title]
- **Date/Time**: [when]
- **Duration**: [length]
- **Platform**: [Zoom, StreamYard, etc.]
- **Goal**: [registrations target, sales target]

## Registration Page Copy
**Headline**: [benefit-driven headline]
**Description**: [what they'll learn]
**Bullets**: [3-5 key takeaways]

## Promotional Plan
### 2 Weeks Before
- [Email 1: Announcement]
- [Social posts: X platforms]

### 1 Week Before
- [Email 2: Value preview]
- [Social posts with countdown]

### Day Before
- [Reminder email]

### Day Of
- [Final reminder 1 hour before]

## Webinar Agenda
| Time | Section | Content | Notes |
|------|---------|---------|-------|
| 0:00 | Welcome | [housekeeping, intro] | [build rapport] |
| 0:05 | Hook | [why this matters] | [create urgency] |
| 0:10 | Content 1 | [teaching section] | [highest value] |
| 0:25 | Content 2 | [teaching section] | [build to offer] |
| 0:35 | Transition | [bridge to offer] | [natural, not salesy] |
| 0:40 | Offer | [present the offer] | [stack value] |
| 0:50 | Q&A | [answer questions] | [handle objections] |
| 0:55 | Close | [final CTA + scarcity] | [deadline] |

## Follow-Up Sequence
- **Immediately**: Replay + offer link
- **Day 1**: Replay reminder + FAQ
- **Day 2**: Case study + offer
- **Day 3**: Last chance + deadline
- **Day 4**: Final email (cart close)

## Tech Checklist
- [ ] Platform set up and tested
- [ ] Slides ready
- [ ] Offer page live
- [ ] Email sequences loaded
- [ ] Replay system configured
```
