# Metrics & Outcomes Review — Sommelier Services

Track, interpret and act on the outcome metrics that matter for a sommelier. The deliverable is a metrics dashboard definition and an interpretation/action review.
This skill is written for a sommelier working with restaurant guests and hospitality businesses in restaurants and wine merchants.

## When to use
- You are a sommelier preparing, delivering or reviewing this part of your work in restaurants and wine merchants.
- You need a defensible, repeatable approach that produces a metrics dashboard definition and an interpretation/action review.
- A colleague, auditor or client asks how this was done and what evidence supports it.

## Workflow
1. **Step 1** - Define each metric precisely — start with wine sales per cover — including source data in wine lists and collection method
2. **Step 2** - Set review cadence and comparison baselines so trends, not single data points, drive decisions
3. **Step 3** - Investigate movements before celebrating or panicking: check data quality, case mix and one-off causes
4. **Step 4** - Link metric movements to practice changes and to risks such as incorrect storage spoiling stock; test one change at a time where possible
5. **Step 5** - Report results honestly to stakeholders in restaurants and wine merchants, including where outcomes fell short and what changes

## Guardrails & Quality Checks
- Never let this happen: incorrect storage spoiling stock.
- Never let this happen: over-service.
- Never let this happen: breakages of valuable bottles.
- Work only within the competence and authority of a sommelier; escalate or refer anything beyond it.
- Record facts and observations, not speculation, and keep records confidential to restaurants and wine merchants's rules.
- Verify names, dates, figures and measurements twice before anything is issued or signed off.
- Use only real, verified information from the case in hand — never invent results, credentials or evidence.
