# Metrics & Outcomes Review — Conveyancing

Track, interpret and act on the outcome metrics that matter for a conveyancer. The deliverable is a metrics dashboard definition and an interpretation/action review.
This skill is written for a conveyancer working with home buyers, sellers and lenders in a conveyancing firm.

## When to use
- You are a conveyancer preparing, delivering or reviewing this part of your work in a conveyancing firm.
- You need a defensible, repeatable approach that produces a metrics dashboard definition and an interpretation/action review.
- A colleague, auditor or client asks how this was done and what evidence supports it.

## Key Concepts
| Term | Meaning |
|------|---------|
| Exchange | when a property sale becomes legally binding |
| Title | the legal evidence of property ownership |
| Stamp duty | a tax payable on property purchases in many jurisdictions |

## Workflow
1. **Step 1** - Define each metric precisely — start with exchange-to-completion times — including source data in contracts and collection method
2. **Step 2** - Set review cadence and comparison baselines so trends, not single data points, drive decisions
3. **Step 3** - Investigate movements before celebrating or panicking: check data quality, case mix and one-off causes
4. **Step 4** - Link metric movements to practice changes and to risks such as missed exchange deadlines; test one change at a time where possible
5. **Step 5** - Report results honestly to stakeholders in a conveyancing firm, including where outcomes fell short and what changes

## Guardrails & Quality Checks
- Never let this happen: missed exchange deadlines.
- Never let this happen: title defects overlooked.
- Never let this happen: fraud attempts undetected.
- Work only within the competence and authority of a conveyancer; escalate or refer anything beyond it.
- Record facts and observations, not speculation, and keep records confidential to a conveyancing firm's rules.
- Verify names, dates, figures and measurements twice before anything is issued or signed off.
- Use only real, verified information from the case in hand — never invent results, credentials or evidence.
