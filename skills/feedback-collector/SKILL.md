# Feedback Collector

## Types Supported
- NPS (Net Promoter Score) surveys
- CSAT (Customer Satisfaction) surveys
- Post-purchase feedback
- Churn surveys (exit interviews)
- Feature request collection
- Employee feedback

## Output includes:
- Survey questions with response types
- Scoring methodology
- Follow-up logic (branch based on responses)
- Analysis framework
- Action plan template based on results
