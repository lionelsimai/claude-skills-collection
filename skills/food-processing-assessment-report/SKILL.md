# Assessment & Findings Report — Food Processing

Assess retailers, wholesalers and consumers and write a defensible findings report as a food production manager. The deliverable is a structured assessment report with findings, evidence and recommendations.
This skill is written for a food production manager working with retailers, wholesalers and consumers in food factories and processing plants.

## When to use
- You are a food production manager preparing, delivering or reviewing this part of your work in food factories and processing plants.
- You need a defensible, repeatable approach that produces a structured assessment report with findings, evidence and recommendations.
- A colleague, auditor or client asks how this was done and what evidence supports it.

| Term | Meaning |

## Workflow
1. **Step 1** - Review the intake record and production plans so the assessment builds on verified information, not assumptions
2. **Step 2** - Carry out the assessment using processing machinery, following the recognised method for food factories and processing plants
3. **Step 3** - Compare findings against the benchmarks behind production yield and note where evidence is strong, weak or missing
4. **Step 4** - Draft the report: findings first, then interpretation, then recommendations in priority order
5. **Step 5** - Check the draft for accuracy and for contamination incidents; have it reviewed where the profession's standards require a second sign-off
