# Troubleshooting & Problem Solving — Property Management

Diagnose and resolve common problems a property manager meets in managed properties and management offices. The deliverable is a troubleshooting guide: symptoms, likely causes, checks and fixes.
This skill is written for a property manager working with landlords, tenants and leaseholders in managed properties and management offices.

## When to use
- You are a property manager preparing, delivering or reviewing this part of your work in managed properties and management offices.
- You need a defensible, repeatable approach that produces a troubleshooting guide: symptoms, likely causes, checks and fixes.
- A colleague, auditor or client asks how this was done and what evidence supports it.

## Workflow
1. **Step 1** - Describe the problem precisely from the record in tenancy agreements — when it started, what changed, who it affects
2. **Step 2** - Work from most likely and most dangerous causes first; rule out anything connected to safety certificates expired early
3. **Step 3** - Run checks in a logical order using property management systems, changing one variable at a time so the cause can be isolated
4. **Step 4** - Apply the fix, then verify against rent collection rates that the problem is actually resolved, not just quieter
5. **Step 5** - Document the diagnosis and fix so the next occurrence is faster, and flag recurring problems for root-cause work
