# Assessment & Findings Report — Actuarial Practice

Assess insurers, pension schemes and regulators and write a defensible findings report as a actuary. The deliverable is a structured assessment report with findings, evidence and recommendations.
This skill is written for a actuary working with insurers, pension schemes and regulators in insurance and pensions offices.

## When to use
- You are a actuary preparing, delivering or reviewing this part of your work in insurance and pensions offices.
- You need a defensible, repeatable approach that produces a structured assessment report with findings, evidence and recommendations.
- A colleague, auditor or client asks how this was done and what evidence supports it.

## Workflow
1. **Step 1** - Review the intake record and valuation reports so the assessment builds on verified information, not assumptions
2. **Step 2** - Carry out the assessment using statistical software, following the recognised method for insurance and pensions offices
3. **Step 3** - Compare findings against the benchmarks behind model validation results and note where evidence is strong, weak or missing
4. **Step 4** - Draft the report: findings first, then interpretation, then recommendations in priority order
5. **Step 5** - Check the draft for accuracy and for model errors affecting reserves; have it reviewed where the profession's standards require a second sign-off
