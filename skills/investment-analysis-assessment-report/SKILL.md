# Assessment & Findings Report — Investment Analysis

This skill is written for a investment analyst working with fund managers, investors and research subscribers in investment firms.

## Workflow
1. **Step 1** - Review the intake record and research reports so the assessment builds on verified information, not assumptions
2. **Step 2** - Carry out the assessment using market data terminals, following the recognised method for investment firms
3. **Step 3** - Compare findings against the benchmarks behind forecast accuracy and note where evidence is strong, weak or missing
4. **Step 4** - Draft the report: findings first, then interpretation, then recommendations in priority order
