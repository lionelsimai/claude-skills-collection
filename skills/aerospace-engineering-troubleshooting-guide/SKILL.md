# Troubleshooting & Problem Solving — Aerospace Engineering

Diagnose and resolve common problems a aerospace engineer meets in design offices, test facilities and hangars. The deliverable is a troubleshooting guide: symptoms, likely causes, checks and fixes.
This skill is written for a aerospace engineer working with aircraft manufacturers, airlines and space agencies in design offices, test facilities and hangars.

## When to use
- You are a aerospace engineer preparing, delivering or reviewing this part of your work in design offices, test facilities and hangars.
- You need a defensible, repeatable approach that produces a troubleshooting guide: symptoms, likely causes, checks and fixes.
- A colleague, auditor or client asks how this was done and what evidence supports it.

## Workflow
1. **Step 1** - Describe the problem precisely from the record in design analyses — when it started, what changed, who it affects
2. **Step 2** - Work from most likely and most dangerous causes first; rule out anything connected to test incidents early
3. **Step 3** - Run checks in a logical order using simulation software, changing one variable at a time so the cause can be isolated
4. **Step 4** - Apply the fix, then verify against test programme milestones that the problem is actually resolved, not just quieter
5. **Step 5** - Document the diagnosis and fix so the next occurrence is faster, and flag recurring problems for root-cause work
