## Workflow
1. **Step 1** - Review the intake record and wine lists so the assessment builds on verified information, not assumptions
2. **Step 2** - Carry out the assessment using cellar management software, following the recognised method for restaurants and wine merchants
3. **Step 3** - Compare findings against the benchmarks behind wine sales per cover and note where evidence is strong, weak or missing
4. **Step 4** - Draft the report: findings first, then interpretation, then recommendations in priority order
5. **Step 5** - Check the draft for accuracy and for incorrect storage spoiling stock; have it reviewed where the profession's standards require a second sign-off
