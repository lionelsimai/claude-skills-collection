# Formal Report Writing — Mine Operations

Write formal reports as a mine operations manager that stand up to scrutiny from any reader. The deliverable is a report template with structure, evidence standards and review steps.
This skill is written for a mine operations manager working with mining companies and mineral buyers in mines and processing plants.

## When to use
- You are a mine operations manager preparing, delivering or reviewing this part of your work in mines and processing plants.
- You need a defensible, repeatable approach that produces a report template with structure, evidence standards and review steps.
- A colleague, auditor or client asks how this was done and what evidence supports it.

## Workflow
1. **Step 1** - Establish the report's purpose, audience and deadline before writing; gather source material from production reports
2. **Step 2** - Structure: summary, background, method, findings, analysis, recommendations — in that order
3. **Step 3** - Write findings factually and separately from opinion; label professional judgement as judgement
4. **Step 4** - Support key points with evidence and with production tonnage where outcomes are claimed; acknowledge limitations openly
5. **Step 5** - Proofread for accuracy and tone, check names, dates and figures twice, and consider underground incidents before release

- Never let this happen: equipment breakdowns.
