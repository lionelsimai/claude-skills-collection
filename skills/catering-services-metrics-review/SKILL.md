# Metrics & Outcomes Review — Catering Services

Track, interpret and act on the outcome metrics that matter for a caterer. The deliverable is a metrics dashboard definition and an interpretation/action review.
This skill is written for a caterer working with event clients and their guests in venues, events and production kitchens.

## When to use
- You are a caterer preparing, delivering or reviewing this part of your work in venues, events and production kitchens.
- You need a defensible, repeatable approach that produces a metrics dashboard definition and an interpretation/action review.
- A colleague, auditor or client asks how this was done and what evidence supports it.

## Key Concepts
| Term | Meaning |
|------|---------|
| BEO | a banquet event order detailing an event's requirements |
| Hot holding | keeping cooked food above a safe temperature |
| Canapé | a small bite-sized item served at receptions |

## Workflow
1. **Step 1** - Define each metric precisely — start with event delivery success — including source data in event orders and collection method
2. **Step 2** - Set review cadence and comparison baselines so trends, not single data points, drive decisions
3. **Step 3** - Investigate movements before celebrating or panicking: check data quality, case mix and one-off causes
4. **Step 4** - Link metric movements to practice changes and to risks such as food temperature abuse in transit; test one change at a time where possible
5. **Step 5** - Report results honestly to stakeholders in venues, events and production kitchens, including where outcomes fell short and what changes

## Output Format
**Context:** [Situation in venues, events and production kitchens] | **Objective:** [What this must achieve] | **Audience:** [event clients and their guests and other stakeholders]

The finished output is a metrics dashboard definition and an interpretation/action review, structured as:
1. Summary of position and evidence
2. Detail, following the workflow above
3. Decisions, actions, owners and dates
4. Review point and escalation route

## Guardrails & Quality Checks
- Never let this happen: food temperature abuse in transit.
- Never let this happen: running out of food.
- Never let this happen: staff shortages on the day.
- Work only within the competence and authority of a caterer; escalate or refer anything beyond it.
- Record facts and observations, not speculation, and keep records confidential to venues, events and production kitchens's rules.
- Verify names, dates, figures and measurements twice before anything is issued or signed off.
- Use only real, verified information from the case in hand — never invent results, credentials or evidence.
