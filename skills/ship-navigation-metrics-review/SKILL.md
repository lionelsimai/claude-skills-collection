# Metrics & Outcomes Review — Ship Navigation

Track, interpret and act on the outcome metrics that matter for a ship's navigation officer. The deliverable is a metrics dashboard definition and an interpretation/action review.
This skill is written for a ship's navigation officer working with ship owners, crews and port authorities in ships' bridges.

## When to use
- You are a ship's navigation officer preparing, delivering or reviewing this part of your work in ships' bridges.
- You need a defensible, repeatable approach that produces a metrics dashboard definition and an interpretation/action review.
- A colleague, auditor or client asks how this was done and what evidence supports it.

| Term | Meaning |

## Workflow
1. **Step 1** - Define each metric precisely — start with voyage plan compliance — including source data in voyage plans and collection method
2. **Step 2** - Set review cadence and comparison baselines so trends, not single data points, drive decisions
3. **Step 3** - Investigate movements before celebrating or panicking: check data quality, case mix and one-off causes
4. **Step 4** - Link metric movements to practice changes and to risks such as groundings and collisions; test one change at a time where possible
5. **Step 5** - Report results honestly to stakeholders in ships' bridges, including where outcomes fell short and what changes
