# Formal Report Writing — Ship Navigation

Write formal reports as a ship's navigation officer that stand up to scrutiny from any reader. The deliverable is a report template with structure, evidence standards and review steps.
This skill is written for a ship's navigation officer working with ship owners, crews and port authorities in ships' bridges.

## When to use
- You are a ship's navigation officer preparing, delivering or reviewing this part of your work in ships' bridges.
- You need a defensible, repeatable approach that produces a report template with structure, evidence standards and review steps.
- A colleague, auditor or client asks how this was done and what evidence supports it.

## Workflow
1. **Step 1** - Establish the report's purpose, audience and deadline before writing; gather source material from voyage plans
2. **Step 2** - Structure: summary, background, method, findings, analysis, recommendations — in that order
3. **Step 3** - Write findings factually and separately from opinion; label professional judgement as judgement
4. **Step 4** - Support key points with evidence and with voyage plan compliance where outcomes are claimed; acknowledge limitations openly
5. **Step 5** - Proofread for accuracy and tone, check names, dates and figures twice, and consider groundings and collisions before release
