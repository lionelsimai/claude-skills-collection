## Workflow
1. **Step 1** - Describe the problem precisely from the record in planning timelines — when it started, what changed, who it affects
2. **Step 2** - Work from most likely and most dangerous causes first; rule out anything connected to supplier failures on the day early
3. **Step 3** - Run checks in a logical order using planning software, changing one variable at a time so the cause can be isolated
4. **Step 4** - Apply the fix, then verify against milestone completion that the problem is actually resolved, not just quieter
5. **Step 5** - Document the diagnosis and fix so the next occurrence is faster, and flag recurring problems for root-cause work
