# Troubleshooting & Problem Solving — Aircraft Maintenance

Diagnose and resolve common problems a aircraft maintenance engineer meets in hangars and line stations. The deliverable is a troubleshooting guide: symptoms, likely causes, checks and fixes.
This skill is written for a aircraft maintenance engineer working with airlines, operators and passengers (indirectly) in hangars and line stations.

## When to use
- You are a aircraft maintenance engineer preparing, delivering or reviewing this part of your work in hangars and line stations.
- You need a defensible, repeatable approach that produces a troubleshooting guide: symptoms, likely causes, checks and fixes.
- A colleague, auditor or client asks how this was done and what evidence supports it.

## Workflow
1. **Step 1** - Describe the problem precisely from the record in maintenance records — when it started, what changed, who it affects
2. **Step 2** - Work from most likely and most dangerous causes first; rule out anything connected to missed inspections early
3. **Step 3** - Run checks in a logical order using aircraft tooling, changing one variable at a time so the cause can be isolated
4. **Step 4** - Apply the fix, then verify against task completion times that the problem is actually resolved, not just quieter
5. **Step 5** - Document the diagnosis and fix so the next occurrence is faster, and flag recurring problems for root-cause work

- Never let this happen: incorrect parts fitted.
- Never let this happen: documentation gaps grounding aircraft.
