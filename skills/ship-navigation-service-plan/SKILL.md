# Service Plan Design — Ship Navigation

Design a realistic, measurable service plan for ship owners, crews and port authorities as a ship's navigation officer. The deliverable is a written plan with goals, actions, owners, timelines and review dates.
This skill is written for a ship's navigation officer working with ship owners, crews and port authorities in ships' bridges.

## When to use
- You are a ship's navigation officer preparing, delivering or reviewing this part of your work in ships' bridges.
- You need a defensible, repeatable approach that produces a written plan with goals, actions, owners, timelines and review dates.
- A colleague, auditor or client asks how this was done and what evidence supports it.

## Workflow
1. **Step 1** - Start from the assessment findings and agree goals with ship owners, crews and port authorities — specific enough to measure against voyage plan compliance
2. **Step 2** - Break each goal into actions sequenced for ships' bridges, naming who does what and by when
3. **Step 3** - Build the plan around voyage plans so progress, changes and decisions are recorded in one place
4. **Step 4** - Price or resource the plan honestly: time, ECDIS chart systems and materials, with contingencies for groundings and collisions
5. **Step 5** - Set the review date and the trigger points that would change the plan, and confirm the plan with all parties
