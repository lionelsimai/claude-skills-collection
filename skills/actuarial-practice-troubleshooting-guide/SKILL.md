# Troubleshooting & Problem Solving — Actuarial Practice

Diagnose and resolve common problems a actuary meets in insurance and pensions offices. The deliverable is a troubleshooting guide: symptoms, likely causes, checks and fixes.

## Workflow
1. **Step 1** - Describe the problem precisely from the record in valuation reports — when it started, what changed, who it affects
2. **Step 2** - Work from most likely and most dangerous causes first; rule out anything connected to model errors affecting reserves early
3. **Step 3** - Run checks in a logical order using statistical software, changing one variable at a time so the cause can be isolated
4. **Step 4** - Apply the fix, then verify against model validation results that the problem is actually resolved, not just quieter
5. **Step 5** - Document the diagnosis and fix so the next occurrence is faster, and flag recurring problems for root-cause work
