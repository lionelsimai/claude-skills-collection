# Metrics & Outcomes Review — Painting & Decorating

Track, interpret and act on the outcome metrics that matter for a painter and decorator. The deliverable is a metrics dashboard definition and an interpretation/action review.
This skill is written for a painter and decorator working with homeowners, landlords and commercial clients in homes, offices and building sites.

## When to use
- You are a painter and decorator preparing, delivering or reviewing this part of your work in homes, offices and building sites.
- You need a defensible, repeatable approach that produces a metrics dashboard definition and an interpretation/action review.
- A colleague, auditor or client asks how this was done and what evidence supports it.

## Workflow
1. **Step 1** - Define each metric precisely — start with job completion times — including source data in quotes and collection method
2. **Step 2** - Set review cadence and comparison baselines so trends, not single data points, drive decisions
3. **Step 3** - Investigate movements before celebrating or panicking: check data quality, case mix and one-off causes
4. **Step 4** - Link metric movements to practice changes and to risks such as falls from height; test one change at a time where possible
5. **Step 5** - Report results honestly to stakeholders in homes, offices and building sites, including where outcomes fell short and what changes

- Never let this happen: falls from height.
- Never let this happen: poor preparation causing early failure.
- Never let this happen: lead paint hazards.
- Work only within the competence and authority of a painter and decorator; escalate or refer anything beyond it.
