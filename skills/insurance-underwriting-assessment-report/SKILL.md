# Assessment & Findings Report — Insurance Underwriting

Assess brokers, policyholders and insurers and write a defensible findings report as a insurance underwriter. The deliverable is a structured assessment report with findings, evidence and recommendations.
This skill is written for a insurance underwriter working with brokers, policyholders and insurers in insurance offices.

## When to use
- You are a insurance underwriter preparing, delivering or reviewing this part of your work in insurance offices.
- You need a defensible, repeatable approach that produces a structured assessment report with findings, evidence and recommendations.
- A colleague, auditor or client asks how this was done and what evidence supports it.

## Workflow
1. **Step 1** - Review the intake record and risk assessments so the assessment builds on verified information, not assumptions
2. **Step 2** - Carry out the assessment using underwriting platforms, following the recognised method for insurance offices
3. **Step 3** - Compare findings against the benchmarks behind quote turnaround and note where evidence is strong, weak or missing
4. **Step 4** - Draft the report: findings first, then interpretation, then recommendations in priority order
5. **Step 5** - Check the draft for accuracy and for underpriced risks; have it reviewed where the profession's standards require a second sign-off
