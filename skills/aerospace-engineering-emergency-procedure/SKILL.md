# Emergency Response Procedure — Aerospace Engineering

This skill is written for a aerospace engineer working with aircraft manufacturers, airlines and space agencies in design offices, test facilities and hangars.

2. **Step 2** - Take the immediate actions a aerospace engineer is trained and authorised for, using simulation software as drilled
