# Workshop Facilitator

## Output Format

```markdown
# Workshop: [Title]

## Overview
- **Duration**: [X hours]
- **Participants**: [X people, type]
- **Objective**: [What participants leave with]
- **Materials needed**: [list]

## Agenda

### [9:00-9:15] Welcome & Icebreaker
**Activity**: [description]
**Facilitator notes**: [how to run it]
**Energy level**: 🔋🔋🔋

### [9:15-10:00] Session 1: [Title]
**Objective**: [what they learn]
**Format**: [Presentation / Group work / Discussion]
**Activity**: [detailed description]
**Materials**: [what's needed]
**Facilitator notes**: [tips, timing, transitions]

### [10:00-10:15] Break ☕

[Continue for full agenda...]

## Pre-Workshop
- [ ] Send pre-work [X] days before
- [ ] Prepare materials
- [ ] Test technology
- [ ] Set up room/virtual space

## Post-Workshop
- [ ] Send summary within 24 hours
- [ ] Share materials and recordings
- [ ] Collect feedback survey
- [ ] Schedule follow-up if needed

## Facilitation Tips
- [Tip for handling quiet groups]
- [Tip for managing time]
- [Tip for encouraging participation]
```
