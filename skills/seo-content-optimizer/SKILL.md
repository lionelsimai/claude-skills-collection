# SEO Content Optimizer

## Workflow
1. Identify target keyword and search intent
2. Analyze top-ranking content
3. Create optimized content structure
4. Apply on-page SEO best practices

## Output Format

```markdown
# SEO Content Plan: [Target Keyword]

## Keyword Research
- **Primary keyword**: [keyword] — [volume] — [difficulty]
- **Secondary keywords**: [list with volumes]
- **Long-tail keywords**: [list]
- **Search intent**: [informational/transactional/navigational]

## Content Blueprint
- **Recommended title**: [H1 with primary keyword]
- **Meta description**: [155 chars with keyword]
- **URL slug**: [clean, keyword-rich URL]
- **Word count target**: [based on competitors]
- **Content type**: [listicle, guide, comparison, etc.]

## Outline (H2/H3 Structure)
[SEO-optimized heading structure]

## On-Page SEO Checklist
- [ ] Primary keyword in title (H1)
- [ ] Primary keyword in first 100 words
- [ ] Keywords in H2/H3 headings
- [ ] Internal links (3-5)
- [ ] External links (2-3 authoritative sources)
- [ ] Images with alt text
- [ ] Meta description under 160 chars
- [ ] URL under 60 chars
- [ ] Schema markup recommendations

## Content Brief
[Detailed brief for writing the article]
```
