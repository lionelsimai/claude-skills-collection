# Metrics & Outcomes Review — Actuarial Practice

Track, interpret and act on the outcome metrics that matter for a actuary. The deliverable is a metrics dashboard definition and an interpretation/action review.
This skill is written for a actuary working with insurers, pension schemes and regulators in insurance and pensions offices.

## When to use
- You are a actuary preparing, delivering or reviewing this part of your work in insurance and pensions offices.
- You need a defensible, repeatable approach that produces a metrics dashboard definition and an interpretation/action review.
- A colleague, auditor or client asks how this was done and what evidence supports it.

## Workflow
1. **Step 1** - Define each metric precisely — start with model validation results — including source data in valuation reports and collection method
2. **Step 2** - Set review cadence and comparison baselines so trends, not single data points, drive decisions
3. **Step 3** - Investigate movements before celebrating or panicking: check data quality, case mix and one-off causes
4. **Step 4** - Link metric movements to practice changes and to risks such as model errors affecting reserves; test one change at a time where possible
5. **Step 5** - Report results honestly to stakeholders in insurance and pensions offices, including where outcomes fell short and what changes

## Guardrails & Quality Checks
- Never let this happen: model errors affecting reserves.
- Never let this happen: stale assumptions.
- Never let this happen: regulatory breaches.
- Work only within the competence and authority of a actuary; escalate or refer anything beyond it.
- Record facts and observations, not speculation, and keep records confidential to insurance and pensions offices's rules.
- Verify names, dates, figures and measurements twice before anything is issued or signed off.
- Use only real, verified information from the case in hand — never invent results, credentials or evidence.
