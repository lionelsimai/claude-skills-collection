# RSVP Conversion Reporter

Report RSVP to attendance conversion from supplied counts.

## Category
- Community — Events
- Tool kind: `analyze`

## Tool
- `rsvp_conversion_reporter` — Report RSVP to attendance conversion from supplied counts.

## Inputs
```json
{
  "type": "object",
  "properties": {
    "counts": {
      "type": "object"
    },
    "amounts": {
      "type": "object"
    },
    "series": {
      "type": "array",
      "items": {
        "type": "number"
      }
    }
  },
  "required": []
}
```

## Example call
```json
{
  "counts": {
    "registrations": 100,
    "check_ins": 90,
    "show_rate": 80,
    "waitlist": 70,
    "no_shows": 60
  }
}
```

## Outputs
- `plugin` and `tool` — identifiers
- `kind` — `analyze`
- `result` — the analyze result, built only from the inputs and this plugin's items: registrations, check-ins, show rate, waitlist, no-shows
- `guardrails` — present on every result
