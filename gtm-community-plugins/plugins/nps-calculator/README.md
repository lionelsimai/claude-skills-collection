# NPS Calculator

Calculate NPS from supplied promoter, passive and detractor counts.

## Category
- Community — Feedback & NPS
- Tool kind: `analyze`

## Tool
- `nps_calculator` — Calculate NPS from supplied promoter, passive and detractor counts.

## Inputs
```json
{
  "type": "object",
  "properties": {
    "counts": {
      "type": "object"
    },
    "amounts": {
      "type": "object"
    },
    "series": {
      "type": "array",
      "items": {
        "type": "number"
      }
    }
  },
  "required": []
}
```

## Example call
```json
{
  "counts": {
    "promoters": 60,
    "passives": 25,
    "detractors": 15,
    "total_responses": 100
  }
}
```

## Outputs
- `plugin` and `tool` — identifiers
- `kind` — `analyze`
- `result` — the analyze result, built only from the inputs and this plugin's items: promoters, passives, detractors, total responses, nps score
- `guardrails` — present on every result
