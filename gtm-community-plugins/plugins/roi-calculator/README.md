# ROI Calculator

Calculate ROI and payback from supplied numbers only.

## Category
- GTM — Proposals & Pricing
- Tool kind: `analyze`

## Tool
- `roi_calculator` — Calculate ROI and payback from supplied numbers only.

## Inputs
```json
{
  "type": "object",
  "properties": {
    "counts": {
      "type": "object"
    },
    "amounts": {
      "type": "object"
    },
    "series": {
      "type": "array",
      "items": {
        "type": "number"
      }
    }
  },
  "required": []
}
```

## Example call
```json
{
  "counts": {
    "current_cost": 100,
    "time_saved_per_week": 90,
    "hourly_rate": 80,
    "tool_cost": 70,
    "payback_weeks": 60
  }
}
```

## Outputs
- `plugin` and `tool` — identifiers
- `kind` — `analyze`
- `result` — the analyze result, built only from the inputs and this plugin's items: current cost, time saved per week, hourly rate, tool cost, payback weeks
- `guardrails` — present on every result

## Guardrails
- No fabrication: use supplied facts only, mark anything missing as `[missing: ...]`
- Drafts only where the tool drafts — human approval required, no auto-send, no auto-post, no auto-remove
- No real people, client names or metrics in examples — fictional sample data only
