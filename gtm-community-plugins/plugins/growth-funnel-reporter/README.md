# Growth Funnel Reporter

Report community growth funnel conversion from supplied counts.

## Category
- Community — Community Analytics
- Tool kind: `analyze`

## Tool
- `growth_funnel_reporter` — Report community growth funnel conversion from supplied counts.

## Inputs
```json
{
  "type": "object",
  "properties": {
    "counts": {
      "type": "object"
    },
    "amounts": {
      "type": "object"
    },
    "series": {
      "type": "array",
      "items": {
        "type": "number"
      }
    }
  },
  "required": []
}
```

## Example call
```json
{
  "counts": {
    "invites": 100,
    "signups": 90,
    "activated": 80,
    "engaged": 70,
    "retained": 60
  }
}
```

## Outputs
- `plugin` and `tool` — identifiers
- `kind` — `analyze`
- `result` — the analyze result, built only from the inputs and this plugin's items: invites, signups, activated, engaged, retained
- `guardrails` — present on every result

## Guardrails
- No fabrication: use supplied facts only, mark anything missing as `[missing: ...]`
- Drafts only where the tool drafts — human approval required, no auto-send, no auto-post, no auto-remove
- No real people, client names or metrics in examples — fictional sample data only
