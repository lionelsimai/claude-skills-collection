# Revenue Mix Reporter

Report revenue mix percentages from supplied amounts.

## Category
- Community — Monetisation
- Tool kind: `analyze`

## Tool
- `revenue_mix_reporter` — Report revenue mix percentages from supplied amounts.

## Inputs
```json
{
  "type": "object",
  "properties": {
    "counts": {
      "type": "object"
    },
    "amounts": {
      "type": "object"
    },
    "series": {
      "type": "array",
      "items": {
        "type": "number"
      }
    }
  },
  "required": []
}
```

## Example call
```json
{
  "amounts": {
    "sponsorship": 1000,
    "tickets": 2000,
    "memberships": 3000,
    "workshops": 4000,
    "other_revenue": 5000
  }
}
```

## Outputs
- `plugin` and `tool` — identifiers
- `kind` — `analyze`
- `result` — the analyze result, built only from the inputs and this plugin's items: sponsorship, tickets, memberships, workshops, other revenue
- `guardrails` — present on every result
