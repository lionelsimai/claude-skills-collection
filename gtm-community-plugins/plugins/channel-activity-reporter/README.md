# Channel Activity Reporter

Report channel activity and unanswered-post risk from supplied counts.

## Category
- Community — Engagement
- Tool kind: `analyze`

## Tool
- `channel_activity_reporter` — Report channel activity and unanswered-post risk from supplied counts.

## Inputs
```json
{
  "type": "object",
  "properties": {
    "counts": {
      "type": "object"
    },
    "amounts": {
      "type": "object"
    },
    "series": {
      "type": "array",
      "items": {
        "type": "number"
      }
    }
  },
  "required": []
}
```

## Example call
```json
{
  "counts": {
    "posts": 100,
    "replies": 90,
    "unique_contributors": 80,
    "unanswered_posts": 70,
    "response_time_hours": 60
  }
}
```

## Outputs
- `plugin` and `tool` — identifiers
- `kind` — `analyze`
- `result` — the analyze result, built only from the inputs and this plugin's items: posts, replies, unique contributors, unanswered posts, response time hours
- `guardrails` — present on every result

## Guardrails
- No fabrication: use supplied facts only, mark anything missing as `[missing: ...]`
- Drafts only where the tool drafts — human approval required, no auto-send, no auto-post, no auto-remove
- No real people, client names or metrics in examples — fictional sample data only
