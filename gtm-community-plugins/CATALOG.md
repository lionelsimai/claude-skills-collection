# Catalogue — 120 GTM + Community Plugins

Recommended path first: use the shared MCP server. One install gives your agent all 120 tools.

## Summary
- Total: 120 plugins — 60 GTM, 60 Community
- Categories: 20 (10 GTM, 10 Community)
- Every plugin: one callable tool, deterministic logic, guardrails on every result
