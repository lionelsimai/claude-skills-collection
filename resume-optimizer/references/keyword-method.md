# Keyword Method — extract, place, and stay honest

## Extract

From the job description text only:

1. Run `scripts/resume_optimizer.py keywords --job job.txt` for a ranked
   candidate list.
2. Read the posting yourself and sort its language into:
   - **Hard skills / tools** — named software, methods, certifications.
   - **Responsibility verbs** — "own", "drive", "analyse", "ship".
   - **Domain terms** — the industry's own nouns ("churn", "pipeline",
     "settlement").
3. Note repeats. A term used three times is a screening term; once may
   be boilerplate.

## Place

- A keyword earns its place inside a bullet that describes the actual
  work: "Built churn dashboard in Power BI used by 3 regional teams"
  beats a bare "Power BI" in a list.
- The skills section is the index, the bullets are the proof. Both
  should carry the term — once each, where true.
- Mirror exact spelling and capitalisation from the posting for tool
  and product names.

## The honesty sort (the three buckets)

For every missing keyword, decide which bucket it is in before writing
anything:

| Bucket | Test | Action |
|---|---|---|
| Present but buried | Can the candidate point to the work in their history? | Surface it, in the posting's words |
| Rephraseable | Is it the same work under a different name? | Rename to the posting's term |
| Genuinely missing | Would the candidate fail a direct interview question on it? | Leave it out; list it as a gap |

If you are unsure which bucket a keyword belongs in, ask the user. Never
decide a bucket silently in the candidate's favour.
