# Rewrite Rules — summary and bullets

## The summary (3–4 lines)

Formula: **target title language + years/scope + strongest matching proof
+ one quantified result (only if real).**

Example shape:
"Growth marketing manager with 6 years in B2B SaaS. Owns paid media and
lifecycle programmes across APAC; grew qualified pipeline 42% year on
year while cutting cost per lead by a fifth."

Rules: no first-person pronouns, no "passionate team player", no claim
that is not backed by a bullet below it.

## Bullets — the XYZ formula

**Accomplished [X] as measured by [Y] by doing [Z]**, led by a strong
verb. One bullet, one result. Start with the result if it is the
strongest part.

- Weak: "Responsible for social media accounts."
- Stronger: "Grew LinkedIn following from 4k to 19k in 12 months with a
  3-post weekly programme built around founder-led content."

Quantification rules:

- Numbers come from the original resume or the user's confirmation in
  session. Nowhere else.
- If a bullet clearly should have a number and none exists, write the
  bullet and mark it `[add metric: e.g. team size, % change, volume]`.
  The user fills it or the mark comes out before submission.
- Ranges and approximations the user states ("about 20 clients") are
  written as stated ("~20 clients"), never sharpened into false
  precision.

## Action-verb bank (grouped)

- **Led**: led, owned, directed, chaired, mentored, hired, coached
- **Built**: built, launched, shipped, designed, automated, migrated
- **Grew**: grew, increased, expanded, doubled, converted, won
- **Improved**: cut, reduced, streamlined, renegotiated, resolved
- **Analysed**: analysed, modelled, forecast, audited, benchmarked

Avoid: "responsible for", "helped with", "worked on", "assisted" —
they hide ownership. If the candidate genuinely assisted, name what
they owned inside the assist.

## Tense and voice

Past tense for finished roles, present or gerund-free simple present
for the current role. No pronouns. Cut adverbs that add no information
("successfully", "effectively", "various").
