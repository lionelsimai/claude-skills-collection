# Cover note — [Candidate] → [Role, Company]

Use this when the gap list has Bucket 3 items (genuinely missing) worth
addressing head-on, or when the portal gives a free-text field. Three
short paragraphs, plain text, no new claims — every line must trace
back to the resume.

## Paragraph 1 — the match (2–3 lines)

[Target role title] + [years/scope] + [the single strongest matching
proof point from the resume, with its real number].

## Paragraph 2 — the proof (2–3 lines)

[Second proof point that maps to a named responsibility in the
posting, in the posting's own vocabulary where truthful.]

## Paragraph 3 — the honest gap, framed (1–2 lines, only if needed)

Name the gap once, plainly, and pair it with the nearest true evidence:
"[Requirement] is the one area I am still building; the closest proof
is [real adjacent experience from the resume]."

Rules: no hype words, no claims the resume does not carry, no apology
spiral — one honest line beats a paragraph of excuses. The candidate
reads and approves the final text before it is sent.
